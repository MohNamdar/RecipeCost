سامانه کنترل قیمت آیتم‌ها - SQLite

اجرا در ویندوز:
1) Python 3 نصب باشد.
2) روی run.bat دوبار کلیک کنید.
3) مرورگر به صورت خودکار روی http://127.0.0.1:4500 باز می‌شود.

هیچ پکیج جانبی لازم نیست.
فایل دیتابیس pricing.db در اجرای اول کنار app.py ساخته می‌شود و همه اطلاعات و تغییرات در آن باقی می‌ماند.
برای بکاپ کافی است از pricing.db یک کپی بگیرید.


قابلیت سختی تهیه:
- برای هر دسته‌بندی می‌توان سختی تهیه از ۱ تا ۵ تعیین کرد.
- سختی دسته به‌صورت خودکار روی همه محصولات همان دسته که سختی اختصاصی ندارند اعمال می‌شود.
- برای هر محصول می‌توان سختی اختصاصی ۱ تا ۵ تعیین کرد؛ در این حالت تغییر سختی دسته روی آن محصول اثر ندارد.
- مقدار پیش‌فرض افزایش قیمت هر سطح سختی ۱۰٪ است: سختی ۱ = ۰٪، ۲ = ۱۰٪، ۳ = ۲۰٪، ۴ = ۳۰٪، ۵ = ۴۰٪.
- درصد افزایش هر سطح از بخش «تنظیمات فرمول» قابل تغییر است.
